## Problem Statement
Develop a Python point-of-sale system to manage cafeteria food items, process customer multi-item orders, compute taxes (5% GST), issue itemized invoices, and generate daily sales reconciliation reports.

**CO Mapping:** CO1, CO3, CO4  |  **PO Mapping:** PO1, PO2, PO3, PO5

---

## Features
- **Dynamic Food Menu Management:** View menu items, add new items with auto-incrementing codes, or remove obsolete items safely.
- **Multi-Item Cart Assembly:** Interactive cart compilation accepting variable quantities with positive quantity enforcement.
- **Statutory Tax & Invoice Generation:** Automatic 5% GST computation and clean terminal receipts.
- **Daily Sales Audit:** Filter historical sales by specific date (`YYYY-MM-DD`) or today's date, displaying order tallies and total revenue.
- **Persistent Storage:** Synchronized automatically with `canteen_data.json`.
