1. Problem Statement & Project Overview

Campus cafeterias and quick-service diners frequently experience peak-hour bottlenecks during breakfast and lunch service. Manual paper tokens result in slow checkout queues, calculation discrepancies, untracked stock modifications, and inaccurate daily revenue reconciliation.

The Canteen Order and Billing Management System was designed and developed by Shreayan to computerise point-of-sale operations. Built entirely with Python's standard library, the application maintains dynamic food catalogs, provides interactive multi-item order cart compilation, automatically enforces a 5% GST computation, prints formatted point-of-sale invoices, and archives every transaction for date-filtered sales audits.

Dynamic Menu Code Generation

Utilizes auto-incrementing key discovery max([int(c) ...]) + 1 to prevent identifier collisions when food offerings expand.

Interactive Cart Assembly

Facilitates arbitrary multi-item ordering within a single checkout session with validation checks against negative or non-integer quantities.

2. System Architecture & Workflow

The software follows a functional controller design backed by a single-file JSON database containing two distinct schemas: a menu map and an orders collection.

Operational Cycle:

  1. Bootstrap: If canteen_data.json does not exist, a default starter menu (Idli, Dosa, Veg Meals, Tea, Coffee) is pre-populated automatically.
  2. Cart Loop: Customer specifies items by numerical code. Quantities are validated (qty > 0), appending items to an in-memory cart list until the keyword done is entered.
  3. Taxation & Invoicing: Computes item subtotal, applies 5% GST via round(subtotal * 0.05, 2), prints an itemized bill, and records the sale timestamped with the current date.

4. Algorithmic Deep Dive & Underlying Logic

A. Auto-Incrementing Code Generator

When adding items, rather than relying on an external counter that could become desynchronized upon deletions, the system evaluates all existing numeric string keys: 

# Extracts all integer keys, defaults to 0 if empty, and increments by 1
new_code = str(max([int(c) for c in data["menu"]] + [0]) + 1)
data["menu"][new_code] = {"name": name, "price": price}
save_data(data)

This guarantees monotonic code generation even if items 2 or 3 are deleted.

B. Financial & Tax Arithmetic

The checkout algorithm computes sum of products, applies GST, and rounds to 2 decimal places to avoid floating point representation anomalies: 

subtotal = sum(i["price"] * i["qty"] for i in cart)
gst = round(subtotal * 0.05, 2)
total = round(subtotal + gst, 2)

C. List Comprehension Date Filter

Daily audits are executed in-memory through clean, idiomatic Python list comprehensions: 

orders = [o for o in data["orders"] if o["date"] == date]
total_sales = round(sum(o["total"] for o in orders), 2)
